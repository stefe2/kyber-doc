    **1. Stephane Beaulieu:**
    > There is some limitation with passthrough and scripts... On the Maestro, If a channel receive position data, this same channel will not be able to move with a script. This is how the Maestro work and not a limitation of the Kyber itself. So what I did in the code to be able to play script with passthrough, I added a deadband in the center to stop sendinng new position to let the script work. So if you select disable deadband it will never stop sending data and the channel will never move wih a script.
